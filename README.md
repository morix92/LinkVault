# LinkVault

LinkVault è una web application fullstack che consente agli utenti di salvare e gestire link personali in modo organizzato e sicuro.

---

## Obiettivi del progetto

- sviluppo frontend con Angular
- sviluppo backend con Node.js ed Express
- persistenza dati con PostgreSQL
- autenticazione multiutente
- containerizzazione tramite Docker
- orchestrazione dei servizi con Docker Compose

---

## Architettura

Frontend:
- Angular

Backend:
- Node.js
- Express

Database:
- PostgreSQL

Infrastructure:
- Docker
- Docker Compose
- Nginx
